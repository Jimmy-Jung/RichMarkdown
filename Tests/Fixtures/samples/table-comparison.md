두 접근 방식을 비교하면 다음과 같습니다.

| 항목 | 네이티브 렌더 | WebView 렌더 |
|---|---|---|
| 첫 표시 지연 | 짧음 | 웹 엔진 초기화 필요 |
| 메모리 | 뷰 수에 비례 | 엔진 고정 비용 + 문서 |
| 텍스트 선택 | 시스템 동작 | 웹 선택 동작 |
| 접근성 | 시스템 API | 웹 접근성 트리 |
| 수식 | \(\LaTeX\) 엔진 필요 | KaTeX/MathJax |
| 유지보수 | OS 업데이트 영향 | 엔진 버전 영향 |

**결론**: ~~항상 네이티브가 빠르다~~ → 측정해야 알 수 있습니다. 특히 *긴 문서*와 **복합 수식**에서 차이가 납니다.
