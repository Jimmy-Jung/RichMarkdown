이차방정식 \(ax^2 + bx + c = 0\) (단, \(a \neq 0\))의 해는 근의 공식으로 구합니다.

\[
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\]

**판별식** \(D = b^2 - 4ac\)의 부호에 따라 해의 개수가 달라집니다.

| 판별식 | 해의 개수 | 예 |
|---|---|---|
| \(D > 0\) | 서로 다른 두 실근 | \(x^2 - 5x + 6 = 0\) → \(x = 2, 3\) |
| \(D = 0\) | 중근 | \(x^2 - 4x + 4 = 0\) → \(x = 2\) |
| \(D < 0\) | 서로 다른 두 허근 | \(x^2 + 1 = 0\) → \(x = \pm i\) |

예를 들어 \(2x^2 - 4x - 6 = 0\)이면 \(a = 2, b = -4, c = -6\)이므로

\[
x = \frac{4 \pm \sqrt{16 + 48}}{4} = \frac{4 \pm 8}{4}
\]

따라서 \(x = 3\) 또는 \(x = -1\)입니다.
