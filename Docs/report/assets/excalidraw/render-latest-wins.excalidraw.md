Excalidraw의 MORE OPTIONS 메뉴에서 이 파일을 그림 보기로 열 수 있습니다.

## Visual Brief

이 절은 그림이 설명하려는 내용과 예시의 범위를 적은 그림 설명입니다. 그림의 영문 용어는 [용어 안내](../../glossary.md)에서 확인할 수 있습니다.

- 핵심 주장: 이전 요청 순서 번호(generation)의 계산 결과는 현재 화면에 반영하지 않습니다.
- 시작과 끝: 첫 요청 g1부터 두 번째 요청 g2의 화면 반영까지
- 주 흐름: 왼쪽에서 오른쪽으로 시간 진행
- 상태 변화: 현재 요청 번호 g1 → 현재 요청 번호 g2
- 등장 주체: 화면 상태 모델 · 작업 처리기 · 결과를 화면에 반영하는 쪽
- 상황 설명: 계산 완료 순서와 화면 반영 조건을 분리한 가상 예입니다.
