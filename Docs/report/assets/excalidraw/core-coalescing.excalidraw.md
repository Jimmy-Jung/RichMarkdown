## Visual Brief

이 절은 그림이 설명하려는 내용과 예시의 범위를 적은 그림 설명입니다. 그림의 영문 용어는 [용어 안내](../../glossary.md)에서 확인할 수 있습니다.

- 핵심 주장: A 실행 중 B와 C가 도착하면 B 대기를 C로 교체합니다.
- 시작과 끝: A 제출부터 C 실행까지
- 주 흐름: 왼쪽에서 오른쪽으로 시간 진행
- 상태 변화: B 대기 → C 대기
- 등장 주체: 입력을 제출하는 쪽 · 다음에 실행할 대기 입력 · 작업 처리기
- 상황 설명: 요청 A·B·C를 단순화한 예이며 처리 시간은 측정값이 아닙니다.
