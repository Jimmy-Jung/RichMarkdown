## Visual Brief

이 절은 그림이 설명하려는 내용과 예시의 범위를 적은 그림 설명입니다. 그림의 영문 용어는 [용어 안내](../../glossary.md)에서 확인할 수 있습니다.

- 핵심 주장: 그림 계산과 웹 화면 반영을 나누고 현재 요청 번호(request ID)의 결과만 반영합니다.
- 시작과 끝: A 그림 생성 시작부터 B 요청과 이전 결과 폐기까지
- 주 흐름: 왼쪽에서 오른쪽으로 시간 진행
- 상태 변화: A 요청 → A의 앱 쪽 요청 취소 + B 요청. 실행 중인 JavaScript를 강제로 멈춘다는 뜻은 아닙니다.
- 등장 주체: 앱 쪽 요청 · JavaScript 그림 계산 · 웹 화면과 높이 반영
- 상황 설명: 현재 요청 번호만 화면에 반영하는 규칙을 설명한 단순화한 예이며 처리 시간은 측정값이 아닙니다.
