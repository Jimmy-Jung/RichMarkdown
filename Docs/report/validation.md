# 0.9.0 릴리스 검수 기록

기준일: 2026-10-07

코드에 반영한 수정과 실제 검사 결과를 대조한 기록입니다. 회귀 테스트는 수정 뒤 기존 기능이나 새로 고친 동작이 다시 깨지지 않는지 확인하는 검사입니다. 수정 전 문제·반영한 코드·보류 조건은 [개선 기록](improvements/README.md), 검사 용어는 [용어 안내](glossary.md)를 참고합니다.

## 2026-10-07 배포 전 재검증

현재 소스의 패키지 전체 검사에서 307개가 통과했고 실패·제외는 0개입니다. Core 빌드, 양 플랫폼 Mermaid JS 회귀, Core 줄 커버리지 94.8% (1336/1409), JavaScript 전체 의존성 감사의 취약점 0건도 확인했습니다. 아래 2026-10-06 결과와 중복 합산하지 않습니다.

초기 병렬 실행에서는 SwiftUI 요청 시작 대기와 MainActor 최대 공백 검사가 실패했습니다. 동기 파싱을 30회 수행하는 순수 기준 측정은 `nonisolated async`로 분리하고, 대기 실패 메시지에 호출 위치를 추가했습니다. 조건과 제한 시간은 유지했습니다. 직렬 실행과 이후 현재 소스 전체 실행에서 각각 307개가 통과했습니다. 표준 CI의 패키지 검사도 직렬 실행 인자를 사용합니다.

이후 전체 실행은 SDK 기능 조회의 표준 출력 종료 대기 문제를 피하는 컴파일러 호출 도우미를 사용했습니다. 이 도우미는 조회 출력 전달 순서만 조정하며 실제 컴파일러·출력 내용·종료 코드는 보존합니다. 테스트 결과 파일에서 307개 개별 검사의 통과를 확인했습니다.

예제 앱 재검사도 단위·화면 검사 합계 48개 통과, 실패 0개, 문서 캡처 제외 1개로 끝났습니다. 실제 테스트 명령의 종료 코드는 0입니다. 결과 수집 도우미는 제외 항목을 실패로 표시했고 컴파일러 메모 위치 하나를 해석하지 못해 수집 상태가 부분 완료였으므로, 성공·실패·제외 판정은 원본 테스트 결과 파일의 요약을 기준으로 확인했습니다.

## 문서·시각자료 검사

2026-10-07에 모듈별 문서를 `architecture/`, `spec/`, `adr/`, `improvements/` 공통 폴더로 통합했습니다. 모듈별 ADR 목차는 공통 `adr/README.md`로 합치고 결정문 파일명에 모듈 이름을 붙였습니다. 이동 후 상대 링크·앵커와 이전 경로 제거를 검사했으며, 구현 설명과 기존 도식 원문은 보존했습니다. 위 실행 결과는 기존 릴리스 검수 기록입니다.

같은 날 기존 보고서 31개와 편집 원본의 그림 설명 4개를 쉬운 한국어로 다듬고 공통 용어 안내를 추가했습니다. 문서별 첫 용어 설명과 예시를 검토하고, 실제 API 이름·수치·요구 ID·기존 실행 결과·미확인 범위를 대조했습니다. 현재 소스와 맞지 않던 코드 색 상태 처리, 웹 뷰 설정, 보안 수정 번들 설명도 정정했습니다.

윤문 뒤 일반 Markdown 32개와 상대 링크·제목 이동 링크를 검사했습니다. Mermaid 15개의 한국어 표시 문구를 밝은·어두운 배경의 PNG 30개로 렌더링하고 직접 확인했으며 공통 문법 범위 경고와 실패는 0건입니다. Excalidraw의 그림 데이터·SVG와 코드 예제는 유지했습니다. 이 문서 검사와 위의 앱 실행 검수는 별도로 구분합니다.

보고서·README·코드 블록 안내의 코드 블록 구분 기호, 표, 상대 링크, 이미지 대체 설명을 검사했습니다. CHANGELOG의 기존 반복 소제목은 유지하고 신규 0.9.0 항목을 별도로 검사했습니다. Mermaid 15개 도식의 밝은·어두운 배경 PNG 30개를 로컬에서 검사했으며, GitHub·VSCode 공통 문법 범위를 벗어났다는 경고와 실패는 0건입니다.

Excalidraw 원본과 SVG 네 쌍이 대응하는지, 화살표 끝과 그림 잘림 문제가 없는지 검사하고 PNG 네 장을 직접 확인했습니다. Mermaid 개념도에는 현재 요청 번호의 결과만 화면에 쓰는 규칙을 반영했습니다.

범용 스타일 검사 도구는 개념도 스킬과 다른 색·선 규칙을 적용해 실패 코드를 반환했습니다. 두 검사 기준의 차이는 별도로 기록하며 전체 스타일 검사를 통과했다고 표현하지 않습니다.

표준 CI(자동 검사)의 출력·Swift 캐시 경로 인자와 Node 검사 실패가 전체 검사를 실패로 끝내는지 간단한 실행 검사로 확인했습니다. 생성된 외부 라이브러리 번들의 문자열 공백은 보존하고, 그 파일만 Git의 공백 형식 검사에서 제외합니다. 보고서에는 개인 이름·로컬 절대 경로·장치/볼륨 식별자·이메일을 포함하지 않았습니다.

최신 Mermaid 테스트의 매크로 경고 2건과 예제 앱의 기존 actor 초기화 함수 경고 2건은 실행 실패와 구분합니다. 실행 실패가 0건이어도 경고까지 0건이라는 뜻은 아닙니다.

## 확인하지 않은 범위

실제 GitHub·VSCode 미리보기, 투명 Excalidraw SVG의 어두운 배경 표시, 선언된 최소 OS의 모든 사용자 환경, 성능 상한, 가능한 공격 입력 전체는 확인하지 않았습니다. 코드·문서 검토나 일부 실행 성공을 이 범위까지 확인한 결과로 확대하지 않습니다. 원본 빌드 로그·테스트 결과 파일·코드 실행 비율·수정 전 실패 결과는 검증 저장소에 별도로 보존합니다.
